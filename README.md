# AgentWatch 🔍

> Who's watching your AI agents?

AgentWatch is a Splunk app that turns your Splunk deployment into a system of record for AI agent behavior — logging every tool call, data access, and action taken by AI agents across your organization, then using Splunk's hosted Foundation-sec model to detect anomalies and generate one-click governance reports.
